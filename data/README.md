# Data Folder

The raw dataset `zomato.csv` (547 MB) is not included in this repository due to GitHub's file size limits.

## How to reproduce this project:
1. Download the dataset from [Kaggle: Zomato Bangalore Restaurants](https://www.kaggle.com/datasets/himanshupoddar/zomato-bangalore-restaurants).
2. Rename the downloaded file to `zomato.csv`.
3. Place it in this `data/` folder.
4. Run the notebooks in the `notebooks/` folder in order to generate `zomato_cleaned.csv`.
